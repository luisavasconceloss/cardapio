### 2. Bug fix: "Erro ao conectar com o servidor" ao confirmar pedido

**Arquivo alterado:** `conexao.php` (em `C:\xampp\htdocs\cardapio\`)

**Problema:** O `conexao.php` tinha um `echo "Conexão realizada com sucesso!"` que era impresso antes do JSON da API, tornando a resposta inválida.

**Exemplo do que acontecia:**
```
Resposta do servidor: Conexão realizada com sucesso!{"success":true,"numero_pedido":"PED-..."}
JSON inválido → .catch() → "Erro ao conectar com o servidor"
```

**Correção:**
- Removido o `echo` da linha 13
- Adicionado tratamento de erro no `catch` (antes ficava silencioso e `$pdo` ficava `null`)

```php
// Antes:
echo "Conexão realizada com sucesso!";
// catch vazio

// Depois:
// (sem echo)
catch (PDOException $e) {
    http_response_code(500);
    echo json_encode(['error' => 'Erro de conexão com o banco de dados']);
    exit();
}
```

**Nota:** Os arquivos estão em dois locais:
- `C:\Users\ana.bessone\Documents\cardapio\` (repositório git)
- `C:\xampp\htdocs\cardapio\` (servidor Apache/XAMPP — este é o que o navegador acessa)

Sempre copiar as alterações para o htdocs depois de editar.

### 3. Bug fix: Página bloqueada após fechar modal de pagamento

**Arquivo alterado:** `cardapio.php` (em `C:\xampp\htdocs\cardapio\`)

**Problema:** Quando o modal de pagamento era fechado, o Bootstrap deixava um `<div class="modal-backdrop">` invisível sobre toda a página, bloqueando cliques.

**Causa:** O evento `hide.bs.modal` dispara ANTES do modal fechar — a limpeza não era efetiva. Também faltava remover o backdrop e a classe `modal-open` do body.

**Correção:** Trocado o evento para `hidden.bs.modal` (depois de fechar) e adicionada limpeza completa:

```javascript
// Antes:
modal.addEventListener('hide.bs.modal', function() {
    removerFoco();
});

// Depois:
modal.addEventListener('hidden.bs.modal', function() {
    removerFoco();
    document.querySelectorAll('.modal-backdrop').forEach(el => el.remove());
    document.body.classList.remove('modal-open');
    document.body.style.paddingRight = '';
    document.body.style.overflow = '';
});
```
